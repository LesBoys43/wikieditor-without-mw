WikiEditor + wikitext2html Demo

原生 DOM / ESM / Codex SVG。编辑器不依赖 MediaWiki 或 jQuery；本示例通过宿主回调接入 wikitext2html npm 包。

先执行 pnpm install 和 pnpm run build，再通过静态 HTTP 服务访问项目根目录下的本页（不要用 file://）。只加载本地模块和翻译，不使用 CDN。

根据渲染器 README，支持粗斜体、标题、列表和外部链接等基础语法；内部链接、表格、模板、文件及扩展语法不保证支持。此处预览不代表完整 MediaWiki 渲染。
